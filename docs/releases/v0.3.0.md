## Changes

- **Advisories without a released fix:** a medium or low advisory that affects the running version but has no released fix is now only a note, not yellow: there is no update to install. Critical and high advisories without a fix stay yellow, and advisories with a released fix are assessed as before. This also changes the assessment of Ethereum nodes: for example, a node that was yellow only because of a medium advisory without a fix is now green, with the advisory listed as a note and still counted in the ADVISORIES column and the `x3f_advisories` metric.
